# OpsBrief

OpsBrief is a decision-support platform that turns maintenance work-order data into daily operational briefs, risk signals, and recurring-issue insights.

## Problem

Maintenance supervisors often depend on fragmented information from CMMS records, spreadsheets, emails, messages, and shift handovers.

OpsBrief helps surface what needs attention instead of only displaying raw maintenance data.

## Version 1

The first version will provide:

- Asset management
- Work-order management
- Overdue work-order detection
- Due-today work-order detection
- High-attention work-order detection
- Recurring asset issue detection
- Daily Operations Brief API
